# 🚀 Wvids Studio Pro — Панель автоматизации, загрузки и аналитики (https://wvids.com/)

Полнофункциональный комплекс на языке **Python** с современной веб-панелью управления, CLI-интерфейсом и **глубокой анонимизацией сетевых пакетов** (антидетект TLS JA3/JA4, HTTP/2 и поведенческий фингерпринтинг).

---

## ✨ Возможности комплекса

1. **Выгрузка видео и фото прямо с ПК:**
   - Поддерживает любые форматы: `.mp4`, `.webm`, `.mov`, `.jpg`, `.png`, `.webp` (до 300 МБ).
   - Загрузка как через перетаскивание (Drag & Drop) в веб-панели, так и по **прямому локальному пути к файлу на диске** (например, `C:\Videos\video.mp4`).
   - Установка **кастомного имени (Title)** и **кастомного описания (Description)** для каждого поста.
   - Автоматическая публикация контента в ленту и на страницу канала.

2. **Смена никнейма аккаунта:**
   - Быстрое изменение имени/логина аккаунта в один клик.
   - Поддержка анти-бот валидации и эмуляция поведенческого трекера `actionfingerprint`.

3. **Авторизация через Cookies:**
   - Поддержка вставки в любом виде:
     - Обычная строка: `auth_user_id=...; auth_sess=...; auth_p=...`
     - JSON-массив из расширений браузера (*Cookie-Editor*, *EditThisCookie* и т.д.)
     - Формат Netscape / cURL
   - Менеджер мульти-аккаунтов: сохранение сессий в базу данных SQLite, переключение между аккаунтами в 1 клик.

4. **Детальная статистика аккаунта:**
   - **Просмотры за сегодня** (Views today) в реальном времени.
   - **Количество подписчиков** (Subscribers).
   - **Общее количество просмотров** (Total views).
   - Интерактивный график динамики просмотров по дням на базе Chart.js.

5. **Глубокая анонимизация пакетов (Антидетект):**
   - **Спуфинг TLS JA3 & JA4** через нативный движок `curl_cffi` (подмена наборов шифров, расширений Client Hello, эллиптических кривых и версий).
   - **Порядок фреймов и псевдо-заголовков HTTP/2:** точное соответствие реальным браузерам (Google Chrome 124, 120, Safari 17, Edge).
   - **Поддержка любых прокси:** HTTP, HTTPS, SOCKS5 и SOCKS5h (с защитой от утечек DNS).
   - **Эмуляция активности (`actionfingerprint`):** генерация зашифрованных координат мыши, дельт скролла и микротаймингов человека для обхода защитных механизмов сайта.
   - **Случайные задержки (Human Jitter):** защита от поведенческого детектирования.

## 🚀 Быстрый запуск Веб-Панели

### Вариант 1 (В один клик через батник):
Просто запустите двойным кликом файл **[start.bat](file:///C:/Coding/LegatoPanel/start.bat)** в папке проекта.
Батник сам проверит наличие Python, доустановит зависимости и сразу откроет панель в браузере.

### Вариант 2 (Через командную строку):
```powershell
python run_panel.py
```
После запуска панель автоматически откроется в вашем браузере по адресу:
👉 **http://127.0.0.1:8088**

## 💻 Использование через консоль (CLI)

Для автоматизации или скриптовых задач доступен инструмент [cli.py](file:///C:/Coding/LegatoPanel/cli.py):

### 1. Авторизация аккаунта:
```powershell
python cli.py login --cookies "auth_user_id=3195151; auth_sess=...; auth_p=..."
```
*(Опционально можно передать `--proxy "socks5://ip:port"` и `--fingerprint "chrome124"`)*

### 2. Просмотр статистики:
```powershell
python cli.py stats
```
Выведет подписчиков, просмотры за сегодня и суммарные просмотры.

### 3. Смена никнейма:
```powershell
python cli.py rename "MyNewNick"
```

### 4. Выгрузка видео или фото с ПК:
```powershell
python cli.py upload --file "C:\MyFiles\video.mp4" --title "Крутой заголовок" --desc "Кастомное описание видео"
```

## 🍪 Какие куки нужны для авторизации?

При входе в свой аккаунт на https://wvids.com/ в браузере:
1. Нажмите `F12` (DevTools) -> вкладка **Application** (или **Хранилище**) -> **Cookies** -> `https://wvids.com`.
2. Скопируйте значения:
   - `auth_user_id` (ваш цифровой ID)
   - `auth_sess` (токен сессии)
   - `auth_p` (дополнительный токен авторизации)
3. Вставьте их в поле во вкладке панели **«Куки & Аккаунты»** в виде:
   ```
   auth_user_id=3195151; auth_sess=MWI5Njg...; auth_p=eyJ2Ij...
   ```
   Либо экспортируйте JSON через расширение *Cookie-Editor* и вставьте целиком. Панель автоматически всё распарсит и подключит аккаунт.
