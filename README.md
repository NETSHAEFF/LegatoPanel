# 🚀 Wvids Studio Pro — Панель автоматизации, загрузки и аналитики (https://wvids.com/)

Полнофункциональный комплекс на языке **Python** с современной веб-панелью управления, CLI-интерфейсом и **глубокой анонимизацией сетевых пакетов** (антидетект TLS JA3/JA4, HTTP/2 и поведенческий фингерпринтинг). Полностью адаптирован под Windows и Ubuntu Linux.

---

## ✨ Возможности комплекса

1. **Выгрузка видео и фото прямо с ПК:**
   - Поддерживает любые форматы: `.mp4`, `.webm`, `.mov`, `.jpg`, `.png`, `.webp` (до 300 МБ).
   - Загрузка как через перетаскивание (Drag & Drop) в веб-панели, так и по **прямому локальному пути к файлу на диске** (например, `videos/video.mp4`).
   - Установка **кастомного имени (Title)** и **кастомного описания (Description)** для каждого поста.
   - Автоматическая публикация контента в ленту и на страницу канала.

2. **Смена никнейма аккаунта:**
   - Быстрое изменение имени/логина аккаунта в один клик.
   - Поддержка анти-бот валидации и эмуляция поведенческого трекера `actionfingerprint`.

3. **Авторизация через Cookies:**
   - Поддержка вставки в любом виде:
     - Обычная строка: `auth_user_id=...; auth_sess=...; auth_p=...`
     - JSON-массив из расширений браузера (*Cookie-Editor*, *EditThisCookie* и т.д.)
     - Формат Netscape / cURL
   - Менеджер мульти-аккаунтов: сохранение сессий в базу данных SQLite, переключение между аккаунтами в 1 клик.

4. **Детальная статистика аккаунта:**
   - **Просмотры за сегодня** (Views today) в реальном времени.
   - **Количество подписчиков** (Subscribers).
   - **Общее количество просмотров** (Total views).
   - Интерактивный график динамики просмотров по дням на базе Chart.js.

5. **Глубокая анонимизация пакетов (Антидетект):**
   - **Спуфинг TLS JA3 & JA4** через нативный движок `curl_cffi` (подмена наборов шифров, расширений Client Hello, эллиптических кривых и версий).
   - **Порядок фреймов и псевдо-заголовков HTTP/2:** точное соответствие реальным браузерам (Google Chrome 124, 120, Safari 17, Edge).
   - **Поддержка любых прокси:** VLESS Reality (Xray), Tor SOCKS5h (с защитой от утечек DNS), HTTP, HTTPS, SOCKS5.
   - **Эмуляция активности (`actionfingerprint`):** генерация зашифрованных координат мыши, дельт скролла и микротаймингов человека для обхода защитных механизмов сайта.
   - **Случайные задержки (Human Jitter):** защита от поведенческого детектирования.

6. **Водяной знак & Уникализация видео через FFmpeg:**
   - **Водяной знак (Watermark) накладывается строго перед уникализацией:**
     - Выбор шрифтов (Arial, Impact, Segoe UI, Tahoma, Trebuchet MS, Calibri, Times New Roman, Georgia, Comic Sans MS). На Ubuntu используются системные шрифты (Liberation, DejaVu) или встроенный шрифт `backend/fonts/default.ttf`.
     - Настройка размера, цвета текста и прозрачности (0–100%).
     - Позиционирование: 9 положений в кадре + точные отступы по осям X и Y.
     - Настраиваемый фон/плашка под текст (цвет, прозрачность, отступы).
     - Поддержка динамических тегов: {username}, {title}, {date}.
     - Живой интерактивный предпросмотр (Live Preview) в веб-интерфейсе в реальном времени.
   - **Глубокая уникализация видео:**
     - **Смена метаданных:** очистка исходных тегов и подмена модели устройства (iPhone 15 Pro, Galaxy S24, Pixel 8 Pro, Xiaomi 14, Sony A7).
     - **Изменение хронометража:** добавление лишних секунд (хвост / стоп-кадр в конце), уменьшение секунд (подрезка) или микро-сдвиг скорости.
     - **Сбивание Perceptual Hash (pHash / dHash):** микро-поворот (0.5°), микро-зум (1.8%), мягкая виньетка, нелинейный сдвиг гаммы.
     - **Сбивание Audio Content ID:** микро-питч тональности (+-20 центов), 3-полосный эквалайзер, микро-эхо.
     - **Сенсорные артефакты:** динамический цифровой шум на каждый кадр.
     - **Кроссплатформенная рандомизация дат:** подмена системных меток atime/mtime и NTFS CreationTime.
     - Встроенный бенчмарк-тест FFmpeg с выводом сдвига pHash и дистанции Хэмминга.

7. **💬 Популярные & Комментирование видео:**
   - **Парсинг раздела «Популярные»:** автоматический парсинг динамической ленты популярных видео на wvids.com с миниатюрами, заголовками, FID и ссылками.
   - **Ручное комментирование в 1 клик:** удобное модальное окно для отправки комментария на любое выбранное видео с выбором активного аккаунта и просмотром существующих комментариев.
   - **Массовый авто-комментер (Бот):**
     - Выбор целей: все популярные, Топ-5, Топ-10 или выбранные галочками вручную.
     - Поддержка синтаксиса рандомизации Spintax (например, `{Класс|Огонь|Супер} видео! 👍`).
     - Случайная человеческая задержка (Human Jitter) между отправками для защиты от лимитов платформы.
     - Ротация нескольких аккаунтов (поочередный постинг с разных добавленных аккаунтов).
     - Живой прогресс-бар, счетчики успеха/ошибок и консоль логов в реальном времени.
   - **История комментирования:** сохранение всех отправленных комментариев, статусов и ссылок в базе данных SQLite.
   - **Поддержка CLI:** команды `popular-list` и `popular-comment`.

## 🐧 Развертывание и работа на Ubuntu / Linux

Панель полностью адаптирована для работы на Ubuntu (20.04, 22.04, 24.04 LTS) — как на серверах без графического интерфейса (Headless VPS), так и на десктопе.

### ⚡ Быстрый старт в 1 команду:
```bash
chmod +x setup_pm2.sh start.sh
./setup_pm2.sh
```

**Что делает `setup_pm2.sh` автоматически:**
1. Устанавливает системные пакеты через `apt`:
   - `python3`, `python3-pip`, `python3-venv`
   - `tor`, `tor-geoipdb`, `obfs4proxy` (изоляция Tor с поддержкой мостов)
   - `ffmpeg` (полная обработка видео, уникализация и наложение водяных знаков)
   - `fonts-dejavu-core`, `fonts-liberation` (кроссплатформенные системные шрифты)
   - `curl`, `build-essential`
2. Проверяет и при необходимости устанавливает официальный **Xray-core** для VLESS Reality.
3. Запускает службу **Tor** на порту 9050.
4. Устанавливает **Node.js** и менеджер процессов **PM2** (если не установлены).
5. Создает виртуальное окружение `./venv` и устанавливает все Python-зависимости.
6. Открывает нужный порт в **UFW** фаерволе и выдает права `setcap` для привязки к порту 80 без sudo.
7. Запускает панель в PM2 в фоновом режиме 24/7 и настраивает сохранение при перезагрузке сервера.

---

### 🕹️ Варианты запуска на Ubuntu:

#### 1. В фоне через PM2 (рекомендуется для VPS):
```bash
./start.sh
```
*(Запустит или перезапустит приложение в PM2)*

#### 2. Напрямую в консоли (Foreground / Debug):
```bash
./start.sh --direct
```
*(Удобно для отладки — весь вывод сервера сразу в вашем терминале)*

#### 3. Консольный CLI через проектный venv:
```bash
./start.sh --cli --help
./start.sh --cli tor status
./start.sh --cli vless start
./start.sh --cli batch --folder videos --interval 5
```

---

### ⚙️ Управление процессом через PM2:
```bash
pm2 status legato-panel     # Проверить статус службы
pm2 logs legato-panel       # Просмотр логов в реальном времени
pm2 restart legato-panel    # Перезапустить панель
pm2 stop legato-panel       # Остановить панель
pm2 startup                 # Сгенерировать команду автозапуска при старте ОС
```

---

### 🌐 Настройка порта (80 / 8080 / кастомный):
По умолчанию панель пытается использовать стандартный порт `80`.
- Если порт 80 занят (например, Apache или Nginx), или запускается от обычного пользователя без sudo, скрипт **автоматически переключится на порт 8080**.
- Вы можете задать любой желаемый порт через переменную окружения:
```bash
PORT=8000 ./start.sh --direct
# или для PM2:
PORT=8000 pm2 start ecosystem.config.js
```
- Чтобы освободить порт 80 от системного веб-сервера:
```bash
sudo systemctl stop nginx 2>/dev/null || sudo systemctl stop apache2 2>/dev/null
```

## 🪟 Запуск на Windows

### Вариант 1 (В один клик):
Дважды кликните по файлу **`start.bat`**.

### Вариант 2 (Через терминал):
```powershell
python run_panel.py
```
После запуска панель откроется в браузере по адресу: **http://127.0.0.1** (порт 80) или **http://127.0.0.1:8080**.

## 💻 Использование через консоль (CLI)

Для скриптов и автоматизации используйте `cli.py` (на Ubuntu через `./start.sh --cli <команда>` или `python cli.py <команда>`):

### 1. Авторизация аккаунта:
```bash
python cli.py login --cookies "auth_user_id=3195151; auth_sess=...; auth_p=..."
```

### 2. Просмотр статистики:
```bash
python cli.py stats
```

### 3. Смена никнейма:
```bash
python cli.py rename "MyNewNick"
```

### 4. Выгрузка видео или фото:
```bash
python cli.py upload --file "videos/myvideo.mp4" --title "Крутой заголовок" --desc "Кастомное описание видео"
```

### 5. Пакетная выгрузка из папки:
```bash
python cli.py batch --folder videos --interval 5 --desc "Описание всех видео"
```

### 6. Управление Tor и VLESS:
```bash
python cli.py tor status
python cli.py tor start
python cli.py vless status
python cli.py vless start
```

## 🍪 Какие куки нужны для авторизации?

При входе в свой аккаунт на https://wvids.com/ в браузере:
1. Нажмите `F12` (DevTools) -> вкладка **Application** (или **Хранилище**) -> **Cookies** -> `https://wvids.com`.
2. Скопируйте значения:
   - `auth_user_id` (ваш цифровой ID)
   - `auth_sess` (токен сессии)
   - `auth_p` (дополнительный токен авторизации)
3. Вставьте их в поле во вкладке панели **«Куки & Аккаунты»** в виде:
   ```
   auth_user_id=3195151; auth_sess=MWI5Njg...; auth_p=eyJ2Ij...
   ```
   Либо экспортируйте JSON через расширение *Cookie-Editor* и вставьте целиком. Панель автоматически всё распарсит и подключит аккаунт.
