🔒 Сторонние прокси полностью отключены: Система настроена исключительно на работу через локальный узел Tor. Все сетевые сокеты и DNS-запросы направляются по протоколу socks5h://127.0.0.1:9150.

⚡ Защита Kill Switch: При случайном закрытии Tor Browser запросы не переключаются на прямое подключение вашего ПК, а немедленно блокируются, предотвращая утечку настоящего IP.

Статус изоляции: АКТИВНА (100% трафика в Tor)
Спецификация защиты и анонимизации

🧅 Полная изоляция трафика через Tor: Весь трафик к wvids.com, серверам загрузки медиа oakroot.top и сопутствующим API принудительно направляется через Tor сеть.

🔒 Zero DNS Leaks (socks5h://): Все доменные имена разрешаются исключительно на удаленном Tor Exit Node, исключая запросы через DNS вашего провайдера.

✔ JA3 / JA4 TLS Fingerprint Spoofing: Подмена нативных шифров (Cipher Suites), криптографических расширений (Extensions) и групп эллиптических кривых.

✔ HTTP/2 Frame Alignment: Полная идентичность структуры фреймов браузера (SETTINGS, WINDOW_UPDATE, порядок псевдо-заголовков :method, :authority, :scheme, :path).

✔ Поведенческий трекер actionfingerprint: Генерация зашифрованных координат курсора, дельт скролла и микро-таймингов для обхода анти-бот систем.
